# IVF Mobile App

An Expo and React Native mobile application with calendar components and stack, drawer, and tab navigation.

## Technology

React Native · Expo · JavaScript · React Navigation

## Getting Started

```bash
git clone https://github.com/ZeeshiCh/IVF.git
cd IVF
npm install
npm start
```

The repository also defines `npm run android`, `npm run ios`, and `npm run web`. Use a compatible emulator, simulator, or device for the selected platform. Platform tooling and any external API configuration must be available before running the app.

## Project Structure

- `src/Screens/` — application screens
- `src/navigation/` — navigation structure
- `src/components/` — reusable components
- `src/utils/` — utilities
